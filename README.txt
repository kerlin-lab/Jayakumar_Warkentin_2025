--README for Relayed-loop optical scan amplification--

This repository contains the data and code for the manuscript 'Relayed-loop optical scan amplification'. The files are organized to allow for the reproduction of all figures presented in the study.

There are two main directories in this repository. The directory titled Fig_Main contains folders for each figure found in the main text of the manuscript. The directory titled Fig_Supp contains folders for all supplemental figures.

Each individual figure folder includes the original source files for the figure, pertinent raw data used in the analysis, and any Python code used to process the data and generate the images or plots. For each figure folder that uses them, the data and Python code can be found in subfolders named accordingly as 'data' and 'python'.

Due to GitHub upload limits, raw data for rhizome and 1 μm bead imaging are not included in this repository. However, they can be made available upon request.

If you have any questions about the figures, data, or the analysis scripts, please contact Dr. Aaron Kerlin (akerlin@umn.edu).
